# Упражнения по C

Решения заданий и запускаемые примеры из материалов преподавателя. Каждое упражнение собирается отдельно. Условие находится в начале исходного файла; пояснения и команды запуска собраны здесь.

## Как запустить

Нужен Visual Studio с компонентом **Desktop development with C++**. Откройте `Exercises.slnx`, выберите нужный проект и назначьте его запускаемым. В консольных программах вводите данные в открывшемся окне; завершение ввода в Windows — **Ctrl+Z**, затем **Enter**.

Из PowerShell в папке репозитория:

```powershell
.\build.ps1
.\build.ps1 -Exercise exercise_3_02
.\bin\exercise_3_02.exe
.\build.ps1 -Exercise exercise_4_05
.\bin\exercise_4_05.exe
```

`build.ps1` собирает все упражнения и примеры. Примеры имеют имена `example_control_flow`, `example_preprocessor`, `example_scope_rules`, `example_particular_pattern`, `example_postfix_calculator`.

### Калькуляторы

Каждая строка — отдельное выражение. После ошибки калькулятор пропускает остаток строки и готов к следующей. Калькуляторы `4-3`–`4-6` разделены на `main.c`, `stack.c`, `getop.c`, `getch.c` и `calc.h`. В `4-10` файл `getch.c` не нужен. Стек рассчитан на 100 чисел; `4-10` принимает строки длиной до 4095 байт без перевода строки.

```text
1 2 - 4 5 + *     => -9
-7 3 %             => -1
3 p d +            => 3, затем 6       (начиная с 4-4)
2 3 pow            => 8               (начиная с 4-5)
0 sin              => 0
0 exp              => 1
5 A =              => 5               (4-6)
A 2 *              => 10
v 1 +              => 11
```

Переменные сохраняются между строками одного запуска. `v` изначально равна нулю и обновляется при печати результата строки или командой `p`. Команда `c` очищает стек, сохраняя переменные. `%` использует `fmod`, поэтому работает и с дробными числами. Тригонометрические функции принимают радианы.

Для `4-7` функция `ungets` использует только `ungetch`. При заполнении буфера возвращается ошибка; уже возвращённая часть строки остаётся в буфере. В `4-8` повторный возврат в занятую ячейку отклоняется с сохранением первого символа. В `4-9` возвращённый `EOF` читается ровно один раз, после чего чтение продолжается из буфера или стандартного ввода.

Макрос `MAXIMUM` предназначен для аргументов без побочных эффектов: выражения вроде `i++` могут вычислиться повторно. Пример препроцессора допускает параметры компиляции `EXAMPLE_DEBUG` и `EXAMPLE_NATION`; тесты проверяют также альтернативную конфигурацию.
